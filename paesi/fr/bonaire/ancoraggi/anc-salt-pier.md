# Salt Pier — bouée de plongée (day-use uniquement) {#anc-salt-pier}

[← Tous les mouillages](../08-ancoraggi.md)
**12°06′18″ N 68°17′24″ W** ★★★ — bouée jaune du site de plongée au sud de Kralendijk (WGS84, estimation — vérifier sur place)

| Champ | Détail |
|---|---|
| **Profondeur** | 5–15 m sable et piles du pier ; récif frangeant près des piles |
| **Tenue de l'ancre** | **Bouée jaune day-use uniquement — mouillage INTERDIT** ; max 2 h, max 13 m, un bateau par bouée ★★★★★ |
| **Vents/abri** | Côte sud-ouest sous le vent, correct par alizé ENE ; houle de sud peut rentrer |
| **Dangers** | **Approche uniquement sans navire Cargill à quai** (chargement de sel) : interdiction temporaire lorsque le navire est à quai ; trafic de bateaux de plongée ; ne pas s'amarrer aux piles |
| **Fréquentation** | Faible-moyenne de jour ; pas pour la nuit — retour au champ de Kralendijk |
| **Bouées/interdictions/réglementation** | Bouée publique jaune pour plongée (nom du site sur la bouée) ; nuitée interdite ; carte STINAPA dive map de référence |
| **À terre** | Aucun service à terre (zone industrielle Cargill au nord) ; snorkeling excellent sous les piles uniquement avec bouée libre |
