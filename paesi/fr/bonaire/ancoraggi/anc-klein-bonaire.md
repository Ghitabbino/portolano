# Klein Bonaire — No Name Beach (day-use uniquement) {#anc-klein-bonaire}

[← Tous les mouillages](../08-ancoraggi.md)
**12°09′36″ N 68°19′00″ W** ★★★ — bouée jaune day-use devant No Name Beach (WGS84, estimation satellite — vérifier sur place)

| Champ | Détail |
|---|---|
| **Profondeur** | 4–10 m sable/corail par taches ; fond qui remonte rapidement vers la plage |
| **Tenue de l'ancre** | **Bouées uniquement — mouillage INTERDIT** (BNMP, réserve intégrale) — max 2 h, max 13 m, un bateau >4 m par bouée ★★★★★ |
| **Vents/abri** | Ouest sous le vent des alizés, bon abri par alizé ENE ; ouvert au sud et sensible à la houle de sud |
| **Dangers** | Récif continu, tortues en nidification (ne pas quitter les sentiers), trafic snorkel/bateaux de plongée 10:00–14:00 très fréquenté ; **nuitée interdite** |
| **Fréquentation** | Fréquentation diurne moyenne-élevée (pic 10–14) — premier arrivé premier servi ; retour obligatoire le soir au champ de Kralendijk ou en marina |
| **Bouées/interdictions/réglementation** | Bouée jaune publique day-use **max 2 h consécutives**, pas pour la nuit ; île inhabitée sans eau/infrastructures, STINAPA Nature Fee obligatoire même sans plongée ★★★★★ |
| **À terre** | Plage sauvage de sable blanc, aucune infrastructure : emporter eau/ombre ; barbecue autorisé uniquement dans les zones prévues, feux ouverts interdits |
