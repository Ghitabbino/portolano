# 02 — Coût de la vie

**Dernière mise à jour: 28/08/2026**

Devise : **USD (dollar US)** — Bonaire est une commune à statut particulier NL (BES) mais seul l'USD circule depuis 2011. Niveau de prix : île à ~90 % importée ; alimentation **~+40 %** vs Pays-Bas européens, restauration touristique chère dans les zones marina/dive-resort. ★★★

> ⚠️ Les rubriques de cette liste sont les mêmes pour tous les pays du guide. Là où la donnée n'a pas encore été trouvée dans les sources, on indique **DONNÉE MANQUANTE** : elle sera recherchée lors du contrôle mensuel (voir [00 Index](00-indice.md)).
