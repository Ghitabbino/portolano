# 08 — Guide des mouillages

**Dernière vérification : 24/08/2026**

## Règles générales de mouillage (d'abord)

- **Anchorage fee obligatoire** si l'on mouille hors marina : **$200 / 12 mois pour ≤50 ft**, **$1 500 / 12 mois pour >100 ft** (intermédiaire **DONNÉE MANQUANTE**) — perçue avec le cruising permit (voir [01 Formalités](01-clearance.md)). Qui reste en marina **ne paie pas** l'anchorage fee pour les jours à quai. ★★★★★
- **Interdiction absolue** de mouiller sur **corail et herbiers** — dégâts punis d'amende. Toujours utiliser **sable clair** visible. ★★★★★
- **Exuma Cays Land and Sea Park (Warderick Wells)** : **uniquement sur mooring** — ancre **interdite** dans tout le parc. Réservation via Bahamas National Trust. ★★★★★
- **Marée 0,8–1,0 m** mais courant dans les **cuts 2–4 nds** — mouiller loin des chenaux de marée. ★★★★

## Notes de mouillage

- **Eau claire** : mouiller toujours sur **sable blanc** bien visible — si vous voyez sombre (corail/herbe) déplacer. ★★★★★
- **Protection alizés** : les Exumas offrent un excellent abri de E/NE derrière les cays — mais exposition à W/NW avec fronts froids hivernaux (déc–fév) — contrôler prévision. ★★★★
- **Affluence** : **déc–avr très élevée** dans les Exumas centre (Warderick, Staniel) — arriver tôt pour prendre mooring/mouillage. ★★★
- **App utile** : **Bahamas Marinas** + **Explorer Charts** + **Navionics** pour les Banks — indispensables. ★★★★

- Les cartes **Explorer** reportent routes, waypoints et profondeurs réellement relevées — plus fiables que les officielles sur les Banks. Achetables à Nassau (Harbour Chandler), en Floride ou en ligne. ★★★★★
- Pour la navigation quotidienne : **traceur + Explorer papier** comme réserve — ne jamais se fier seulement à l'électronique sur les Banks. ★★★★★

## Non inclus (pour l'instant)

- **Abacos — Man-O-War Cay, Great Guana Cay** : mouillages secondaires → données insuffisantes, **à vérifier**
- **Ragged Islands / Jumentos** : reculés, magnifiques mais zéro services → **à vérifier**
- **South Andros / Acklins** : peu fréquentés — **DONNÉE MANQUANTE**

## Checklist mouillage pour les Bahamas

1. Anchorage fee payée avec Click2Clear (si mouillage hors marina) ✓
2. Cartographie Explorer à bord + électronique à jour ✓
3. Ancre légère mais avec beaucoup de chaîne — tenue excellente sur sable, mauvaise sur corail
4. Observer la couleur de l'eau : **blanc = sable ok, sombre = corail non**
5. Étal pour les cuts entre Banks et Sound ✓
6. Réservation mooring Warderick Wells si cap sur le parc ✓
